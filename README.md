# Multiplayer-System

**Multiplayer System** is a powerful Unreal Engine plugin that simplifies multiplayer session management.  
It allows you to **create**, **find**, and **join** multiplayer sessions based on custom session names provided by the user — giving complete flexibility and control over the multiplayer experience.

---

## 💡 Overview

This plugin provides a ready-to-use system for handling Unreal Engine’s **Online Subsystem** session flow with minimal setup.  
It manages everything from session creation to discovery and joining — all through easy-to-use **Blueprint nodes** or **C++ functions**.

---

## ✨ Features

- 🧩 **Create**, **Find**, and **Join** multiplayer sessions  
- 🔤 Search sessions by **custom session name**  
- 🕹️ Works with **LAN** or **Online (Steam)** subsystems  
- 🧠 Simple **Blueprint-based workflow** (no extra C++ needed)  
- ⚙️ Full flexibility — user-defined session names and parameters   
- 💻 Works seamlessly on **Windows**, **Linux**

---

## 🚀 How It Works

1. **Create a Session** — Provide a session name and number of players.  
2. **Find Sessions** — Search active sessions using the session name.  
3. **Join Session** — Connect to any discovered session instantly.  
4. **Travel Between Levels** — Integrated support for seamless multiplayer travel.

All core logic is handled internally by the plugin, so you can focus on gameplay instead of networking setup.

---

## 🧱 Use Cases

---

## 🛠️ Installation

1. Copy or clone the plugin into your Unreal project
2. Open Unreal Engine Project → **Edit → Plugins**
3. Enable **Multiplayer System** and restart the editor.

---

## 📦 Compatibility

- Unreal Engine 5
- Windows, Linux 
- Supports Blueprint and C++ projects  
- Compatible with Steam, and LAN subsystems
